# Japanese Learning Web Service

일본어 학습 중 발견한 표현을 저장하고,
역번역 퀴즈와 오답 재학습을 통해
수동적인 이해를 능동적인 표현 능력으로 연결하는 웹 서비스입니다.

## Core Learning Flow

표현 저장
→ 역번역 퀴즈
→ 정답·오답 기록
→ 오답 재학습
→ 학습 기록 확인
