# Problem Definition

## 1. 프로젝트 배경

일본어를 공부하면서 기사, 영상, 교재, 회화 연습 등 다양한 상황에서 모르는 단어나 문장을 발견했다.

이러한 표현을 메모장, 노트, 스크린샷 등 여러 장소에 기록했지만, 기록한 이후 다시 확인하거나 실제로 사용해보는 경우는 많지 않았다.

그 결과 학습할 당시에는 이해했던 표현도 시간이 지나면 잊어버리거나, 일본어를 보면 의미는 이해할 수 있지만 한국어에서 일본어로 직접 표현하려고 하면 쉽게 떠오르지 않는 문제가 있었다.

또한 틀렸던 표현을 따로 관리하지 않았기 때문에 같은 표현을 반복해서 틀리는 경우도 있었다.

---

## 2. 발견한 문제

일본어 학습 과정에서 다음과 같은 문제를 경험했다.

### 학습 자료가 여러 곳에 흩어진다

모르는 단어와 문장을 메모장, 노트, 스크린샷 등 서로 다른 장소에 기록하기 때문에 나중에 필요한 표현을 다시 찾기 어렵다.

### 기록이 복습으로 연결되지 않는다

표현을 기록하는 것으로 학습이 끝나는 경우가 많으며, 저장한 내용을 다시 꺼내보거나 테스트하는 과정이 부족하다.

### 이해한 표현을 직접 사용하기 어렵다

일본어를 보고 뜻을 이해하는 것은 가능하지만, 한국어를 보고 같은 내용을 일본어로 바로 표현하기는 어렵다.

즉, 수동적인 이해와 능동적인 표현 사이에 차이가 존재한다.

### 오답을 반복해서 학습하기 어렵다

틀렸던 단어나 문장을 체계적으로 저장하지 않기 때문에 무엇을 반복해서 공부해야 하는지 알기 어렵다.

### 학습 과정을 확인하기 어렵다

얼마나 많은 표현을 학습했고, 어떤 표현을 자주 틀리며, 얼마나 복습했는지를 확인하기 어렵다.

---

## 3. 핵심 사용자 문제

이 프로젝트에서 가장 먼저 해결하려는 문제는 다음과 같다.

> 일본어 학습자는 공부 중 새로운 표현을 기록하지만, 기록한 내용을 다시 복습하거나 직접 일본어로 떠올리는 과정이 부족해 학습한 표현이 실제 표현 능력으로 연결되지 않는다.

따라서 단순히 일본어 표현을 저장하는 기능보다,

**표현 저장 → 직접 떠올리기 → 오답 기록 → 다시 학습하기**

라는 반복 학습 흐름을 만드는 것을 핵심 목표로 한다.

---

## 4. 해결 방법

사용자가 학습 중 발견한 일본어 단어와 문장을 하나의 서비스에 저장할 수 있도록 한다.

저장한 표현은 한국어를 보고 일본어를 입력하는 역번역 퀴즈에 다시 사용한다.

퀴즈에서 틀린 표현은 오답으로 기록하고, 사용자가 오답만 다시 학습할 수 있도록 한다.

이를 통해 표현을 단순히 기록하는 것으로 끝내지 않고 반복적으로 다시 떠올리는 학습 과정으로 연결한다.

기본 학습 흐름은 다음과 같다.

표현 발견
→ 표현 저장
→ 역번역 퀴즈
→ 정답·오답 기록
→ 오답 재학습
→ 학습 기록 확인

---

## 5. 핵심 사용자

초기 주요 사용자는 다음과 같다.

* 한국어를 모국어로 사용하는 일본어 학습자
* JLPT N3~N2 정도의 기본적인 일본어 이해 능력을 가진 사용자
* 기사, 영상, 교재 등에서 새로운 표현을 자주 발견하는 사용자
* 단어나 문장을 기록하지만 체계적으로 복습하지 않는 사용자
* 일본어를 읽으면 이해할 수 있지만 직접 말하거나 쓰는 데 어려움을 느끼는 사용자

초기 개발에서는 모든 일본어 학습자를 대상으로 하기보다 이러한 문제를 가진 사용자의 학습 흐름에 집중한다.

---

## 6. 프로젝트에서 해결하지 않는 문제

MVP 단계에서는 다음 문제를 직접 해결하지 않는다.

* 일본어 문법 강의
* 자동 번역
* AI 문법 설명
* AI 회화
* 음성 인식
* OCR
* JLPT 전체 학습 관리
* 커뮤니티
* 고급 간격 반복 알고리즘

이러한 기능은 핵심 학습 흐름을 검증한 이후 실제 사용자 필요성이 확인될 경우 추가로 검토한다.

---

## 7. 프로젝트의 핵심 가설

사용자가 학습 중 발견한 표현을 한곳에 저장하고, 저장한 표현을 역번역 문제로 다시 떠올리게 하며, 틀린 표현을 반복해서 학습할 수 있도록 하면 단순히 기록만 하는 것보다 학습 내용을 다시 사용할 가능성이 높아질 것이다.

MVP를 배포한 뒤 직접 사용하고 다른 일본어 학습자의 피드백을 받아 이 가설을 검증한다.
