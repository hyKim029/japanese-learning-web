# Problem Definition

## 1. 프로젝트 배경

일본어를 공부하면서 기사, 영상, 교재, 회화 연습 등 다양한 상황에서 모르는 단어나 문장을 발견했다.

이러한 표현을 메모장, 노트, 스크린샷 등 여러 장소에 기록했지만, 기록하는 것 자체로 학습을 끝내는 경우가 많았다. 저장한 표현을 나중에 다시 확인하거나 직접 사용해보는 과정이 체계적으로 이루어지지 않았고, 시간이 지나면서 많은 표현이 단순한 기록으로만 남게 되었다.

그 결과 학습할 당시에는 이해했던 표현도 시간이 지나면 잊어버리거나, 일본어를 보면 의미를 이해할 수 있지만 한국어에서 일본어로 직접 말하거나 쓰려고 하면 쉽게 떠오르지 않는 문제가 있었다.

특히 일본어 실력을 높이기 위해서는 새로운 표현을 많이 접하는 것뿐만 아니라, 이미 학습한 표현을 다시 떠올리고 직접 사용하는 과정이 중요하다고 느꼈지만 기존 학습 방식에서는 이러한 복습과 출력 연습을 지속하기 어려웠다.

또한 틀렸던 표현을 따로 관리하지 않았기 때문에 같은 표현을 반복해서 틀리더라도 무엇을 다시 학습해야 하는지 체계적으로 확인하기 어려웠다.

---

## 2. 발견한 문제

일본어 학습 과정에서 다음과 같은 문제를 경험했다.

### 학습 자료가 여러 곳에 흩어진다

모르는 단어와 문장을 메모장, 노트, 스크린샷 등 서로 다른 장소에 기록하기 때문에 나중에 필요한 표현을 다시 찾기 어렵다.

저장한 위치를 기억하지 못하거나 여러 기록을 다시 확인해야 하기 때문에 학습한 표현을 다시 꺼내보는 것 자체가 번거로워진다.

### 기록이 복습으로 연결되지 않는다

새로운 표현을 발견했을 때 기록하는 것으로 학습을 끝내는 경우가 많았다.

저장한 표현을 다시 확인하거나 스스로 떠올려보는 과정이 정해져 있지 않아 기록은 계속 쌓이지만 실제 복습으로 연결되지 않았다.

### 이해한 표현을 직접 사용하기 어렵다

일본어 단어나 문장을 보면 의미를 이해할 수 있어도, 한국어를 보고 같은 내용을 일본어로 직접 표현하려고 하면 쉽게 떠오르지 않는 경우가 많았다.

즉, 일본어를 보고 이해하는 **수동적인 이해**와 필요한 상황에서 일본어를 직접 떠올리는 **능동적인 표현** 사이에 차이가 존재했다.

기존 학습에서는 일본어를 읽고 의미를 확인하는 과정은 많았지만, 학습했던 표현을 아무런 힌트 없이 다시 떠올리는 연습은 상대적으로 부족했다.

### 오답을 반복해서 학습하기 어렵다

틀렸던 단어나 문장을 체계적으로 기록하지 않기 때문에 어떤 표현을 자주 틀리는지 확인하기 어렵다.

한 번 틀린 표현을 다시 학습할 기준이나 흐름이 없어 같은 표현을 반복해서 틀리더라도 이후 학습으로 자연스럽게 연결되지 않았다.

### 학습 과정을 확인하기 어렵다

얼마나 많은 표현을 저장했는지는 확인할 수 있어도 실제로 얼마나 복습했고, 어떤 표현을 자주 틀렸으며, 어떤 내용을 다시 학습해야 하는지 확인하기 어렵다.

따라서 단순한 학습량이 아니라 실제 복습 과정과 학습 상태를 파악하기 어렵다는 문제가 있었다.

---

## 3. 핵심 사용자 문제

이 프로젝트에서 가장 먼저 해결하려는 문제는 다음과 같다.

> 일본어 학습 중 새로운 표현을 기록하지만, 기록한 내용을 다시 능동적으로 떠올리는 복습 과정이 부족해 학습한 표현이 실제 말하기와 쓰기 능력으로 연결되지 않는다.

특히 이 프로젝트에서는 다음 두 문제의 연결에 집중한다.

1. **학습한 표현을 기록하지만 다시 복습하지 않는다.**
2. **그 결과 일본어를 보면 이해할 수 있지만 필요할 때 직접 일본어로 떠올리기 어렵다.**

즉, 문제의 핵심은 단순히 학습 내용을 저장할 장소가 부족한 것이 아니라 **저장한 내용을 다시 꺼내 사용하는 학습 과정이 부족하다는 것**이다.

따라서 단순한 일본어 단어장이나 메모 서비스를 만드는 것보다,

**표현 저장 → 능동적으로 떠올리기 → 오답 확인 → 다시 학습하기**

라는 반복 학습 흐름을 만드는 것을 프로젝트의 핵심 목표로 한다.

---

## 4. 해결 방법

사용자가 기사, 영상, 교재, 회화 연습 등에서 발견한 일본어 단어와 문장을 하나의 서비스에 저장할 수 있도록 한다.

그러나 표현을 저장하는 것 자체를 최종 목표로 하지 않는다.

저장한 표현을 이후 한국어에서 일본어로 바꾸는 **역번역 퀴즈**로 다시 출제하여 사용자가 정답을 보기 전에 직접 일본어 표현을 떠올리도록 한다.

이를 통해 단순히 일본어를 보고 의미를 확인하는 방식에서 벗어나, 학습한 표현을 능동적으로 회상하는 연습으로 연결한다.

퀴즈에서 틀린 표현은 오답으로 기록하고, 사용자가 오답 항목만 다시 학습할 수 있도록 한다. 반복해서 틀리는 표현 역시 확인할 수 있도록 하여 복습해야 할 내용을 스스로 판단하기 쉽게 만든다.

기본 학습 흐름은 다음과 같다.

**표현 발견
→ 표현 저장
→ 역번역 퀴즈
→ 직접 일본어 떠올리기
→ 정답·오답 기록
→ 오답 재학습
→ 학습 기록 확인**

이를 통해 기존의

**표현 발견 → 기록 → 학습 종료**

흐름을

**표현 발견 → 저장 → 회상 → 확인 → 반복**

이라는 학습 루프로 변화시키는 것을 목표로 한다.

---

## 5. 핵심 사용자

초기 주요 사용자는 다음과 같다.

* 한국어를 모국어로 사용하는 일본어 학습자
* JLPT N3~N2 정도의 기본적인 일본어 이해 능력을 가진 사용자
* 기사, 영상, 교재, 회화 연습 등에서 새로운 표현을 자주 발견하는 사용자
* 새로운 단어나 문장을 메모하지만 저장한 내용을 체계적으로 다시 복습하지 않는 사용자
* 일본어를 읽으면 의미를 이해할 수 있지만 직접 말하거나 쓰려고 하면 표현이 쉽게 떠오르지 않는 사용자
* 자신이 자주 틀리는 표현을 모아서 다시 학습하고 싶은 사용자

초기 개발에서는 일본어를 처음 시작하는 학습자나 모든 유형의 일본어 학습자를 대상으로 하지 않는다.

기본적인 일본어 지식은 가지고 있지만,

> **알고 있는 일본어를 실제로 사용할 수 있는 일본어로 바꾸는 과정에서 어려움을 느끼는 학습자**

에게 우선적으로 집중한다.

초기에는 개발자인 본인 역시 핵심 사용자 중 한 명으로 서비스를 실제 일본어 학습 과정에서 사용하고, 이후 비슷한 문제를 경험하는 일본어 학습자의 피드백을 받아 사용성을 검증한다.

---

## 6. 프로젝트에서 해결하지 않는 문제

MVP 단계에서는 다음 문제를 직접 해결하지 않는다.

* 일본어 문법 강의
* 자동 번역
* AI 문법 설명
* AI 회화
* 음성 인식
* OCR
* JLPT 전체 학습 과정 관리
* 커뮤니티
* 사용자 간 경쟁이나 랭킹
* 복잡한 게임화 기능
* 고급 간격 반복 알고리즘

이 프로젝트의 초기 목적은 종합적인 일본어 교육 플랫폼을 만드는 것이 아니다.

우선

**표현 저장 → 능동적 회상 → 오답 확인 → 반복 학습**

이라는 핵심 학습 흐름이 실제 사용자 문제를 해결하는지를 검증한다.

추가 기능은 MVP 배포 및 사용자 테스트 이후 실제 필요성이 확인되는 경우에만 검토한다.

---

## 7. 프로젝트의 핵심 가설

이 프로젝트에서는 다음 가설을 검증한다.

> 사용자가 일본어 학습 중 발견한 표현을 한곳에 저장하고, 저장한 표현을 한국어에서 일본어로 바꾸는 역번역 문제로 다시 떠올리게 하며, 틀린 표현을 반복해서 학습할 수 있도록 하면 단순히 표현을 기록하고 끝내는 방식보다 학습한 표현을 다시 사용하고 복습하는 행동을 유도할 수 있을 것이다.

이를 확인하기 위해 다음과 같은 사용자 행동을 관찰한다.

* 저장한 표현을 실제로 다시 퀴즈에서 학습하는가
* 한 번 틀린 표현을 다시 복습하는가
* 표현을 저장하는 것에서 학습을 끝내지 않고 반복 학습으로 이어지는가
* 역번역 방식이 일본어 표현을 직접 떠올리는 연습에 도움이 된다고 느끼는가

MVP를 배포한 이후 먼저 실제 일본어 학습 과정에서 직접 사용하고, 비슷한 학습 경험을 가진 사용자에게 테스트를 요청한다.

사용 과정에서 발견한 불편과 피드백을 기록하고, 핵심 학습 흐름에 영향을 주는 문제부터 개선한다.

---

## 8. 핵심 학습 루프

프로젝트 전체 기능의 우선순위를 결정하는 기준은 다음 학습 루프이다.

### 기존 학습 방식

**새로운 표현 발견
→ 메모 또는 스크린샷
→ 저장
→ 학습 종료**

### 개선하고자 하는 학습 방식

**새로운 표현 발견
→ 한곳에 저장
→ 역번역 퀴즈로 다시 출제
→ 일본어를 직접 떠올림
→ 정답 확인
→ 오답 기록
→ 오답 다시 출제
→ 반복 학습**

따라서 새로운 기능을 추가할 때는 해당 기능이 이 학습 루프를 실제로 개선하는지 우선적으로 판단한다.

핵심 학습 루프와 직접적인 관련성이 낮은 기능은 MVP 이후로 미룬다.

---

## 9. 프로젝트 핵심 목표

이 프로젝트의 목표는 단순히 일본어 학습 내용을 저장하는 서비스를 만드는 것이 아니다.

> **기록하고 잊어버리던 일본어 표현을 다시 꺼내 쓰게 만드는 학습 흐름을 만드는 것**

을 핵심 목표로 한다.

이를 위해 MVP에서는 다음 네 단계가 실제로 연결되는 것을 가장 중요하게 생각한다.

**1. 표현 저장
2. 역번역을 통한 능동적 회상
3. 오답 기록
4. 오답 반복 학습**

이 네 단계가 완성된 시점을 첫 번째 MVP의 핵심 기능 완성으로 정의한다.
