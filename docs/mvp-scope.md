# MVP Scope

## P0 - Must Have

- 회원가입 / 로그인
- 표현 등록
- 표현 조회
- 표현 수정 / 삭제
- 검색
- 역번역 퀴즈
- 정답 / 오답 기록
- 오답 목록
- 오답 복습
- 반응형 UI

## P1 - Should Have

- 태그
- 필터
- 학습 완료 상태
- 학습 기록

## P2 - Later

- AI 자동 채점
- AI 문법 설명
- TTS
- 음성 입력
- OCR
- 간격 반복 알고리즘
- JLPT 자동 분류
- 커뮤니티

MVP의 완료 기준은 표현을 저장하고, 저장한 표현을 역번역 퀴즈로 회상하고, 틀린 표현을 다시 복습하는 핵심 학습 루프가 실제 사용자 데이터로 끝까지 동작하는 것이다.
