# User Persona

## 1. 핵심 사용자

### 기본 정보

* 한국어를 모국어로 사용하는 일본어 학습자
* 일본어 초급 단계를 지나 기본적인 문법과 어휘를 알고 있음
* 대략 JLPT N3~N2 수준
* JLPT, 일본 취업, 일본 콘텐츠 이해, 회화 능력 향상 등을 목적으로 일본어를 공부하고 있음
* PC와 스마트폰을 모두 사용함

---

## 2. 학습 행동

사용자는 일본어를 공부하면서 다양한 곳에서 새로운 표현을 접한다.

예를 들면 다음과 같다.

* JLPT 문제집
* 일본어 기사
* YouTube 및 영상 콘텐츠
* 애니메이션이나 드라마
* 일본어 회화 연습
* SNS
* 일본인과의 대화

새로운 단어나 표현을 발견하면 메모장, 노트, 스크린샷 등에 기록한다.

하지만 기록 방법이 일정하지 않고, 기록한 내용을 다시 복습하는 과정도 정해져 있지 않다.

---

## 3. 주요 문제

### 기록한 표현을 다시 보지 않는다

새로운 표현을 발견했을 때 기록하지만, 이후 다시 확인할 계기가 없어 기록이 계속 쌓이기만 한다.

### 일본어를 보면 알지만 직접 표현하기 어렵다

일본어 표현을 보면 뜻을 이해할 수 있지만 한국어를 보고 같은 내용을 일본어로 표현하려고 하면 바로 떠오르지 않는다.

### 틀렸던 표현을 반복해서 틀린다

학습 중 틀렸던 표현이 어디에 기록되어 있는지 알기 어렵고, 다시 학습할 기준도 없어 같은 실수를 반복한다.

### 학습 내용이 서로 연결되지 않는다

독해에서 발견한 표현이 회화 연습이나 작문 연습으로 이어지지 않고 각각의 학습 활동이 분리되어 있다.

---

## 4. 사용자의 목표

사용자는 단순히 많은 일본어 표현을 저장하는 것이 목표가 아니다.

다음과 같은 상태를 만들고 싶어 한다.

* 공부하면서 발견한 표현을 한곳에 모으기
* 이전에 공부했던 표현을 다시 확인하기
* 한국어만 보고 일본어 표현을 직접 떠올리기
* 잘 떠오르지 않는 표현을 반복해서 학습하기
* 읽어서 이해할 수 있는 표현을 실제로 사용할 수 있는 표현으로 만들기

즉,

> **「보면 아는 일본어」를 「직접 사용할 수 있는 일본어」로 바꾸는 것**

이 핵심 목표이다.

---

## 5. 사용 환경

### 모바일

외부에서 일본어 표현을 발견했을 때 빠르게 저장하는 용도로 사용한다.

예:

* 영상을 보다가 모르는 표현을 발견했을 때
* 이동 중 일본어 기사를 읽을 때
* 회화 연습 후 기억하고 싶은 표현을 저장할 때

따라서 모바일에서는 표현 등록 과정이 빠르고 단순해야 한다.

### PC

본격적인 복습과 학습에 사용한다.

예:

* 저장한 표현 정리
* 역번역 퀴즈
* 오답 복습
* 학습 기록 확인

단, 모바일에서도 퀴즈와 복습 기능을 사용할 수 있어야 한다.

---

## 6. 핵심 니즈

사용자의 핵심 니즈를 우선순위로 정리하면 다음과 같다.

### 1순위

저장한 일본어 표현을 다시 학습할 수 있어야 한다.

### 2순위

한국어를 보고 일본어를 직접 떠올리는 연습을 할 수 있어야 한다.

### 3순위

틀린 표현을 자동으로 모아서 다시 학습할 수 있어야 한다.

### 4순위

새로운 표현을 발견했을 때 번거롭지 않게 저장할 수 있어야 한다.

### 5순위

자신이 얼마나 학습하고 복습했는지 확인할 수 있어야 한다.

---

## 7. 초기 사용자 범위

MVP에서는 다음 사용자를 우선 대상으로 하지 않는다.

* 히라가나와 가타카나부터 배우는 완전 초보자
* 일본어 강의를 원하는 사용자
* JLPT 문제 자체를 제공받고 싶은 사용자
* AI와 자유 회화를 주목적으로 하는 사용자
* 일본어 번역기를 원하는 사용자

Kotoba Loop의 초기 핵심 사용자는 이미 어느 정도 일본어를 공부하고 있으며,

> **배운 표현은 많지만 그것을 반복해서 복습하고 직접 사용하는 과정이 부족한 학습자**

이다.
