# User Scenarios

## Scenario 1. 새로운 일본어 표현 저장

### 상황

사용자는 일본어 기사나 영상을 보다가 모르는 표현을 발견한다.

예를 들어 다음 표현을 처음 알게 되었다.

> 立ち止まる
> 멈춰 서다

기존에는 메모장이나 스크린샷으로 남겨두었지만 이후 다시 확인하지 않는 경우가 많았다.

### 사용자 목표

현재 보고 있는 콘텐츠의 흐름을 크게 방해하지 않으면서 새로운 표현을 빠르게 저장하고 싶다.

### 사용자 행동

1. Kotoba Loop를 실행한다.
2. `새 표현 등록`을 선택한다.
3. 일본어 표현을 입력한다.
4. 한국어 뜻을 입력한다.
5. 필요한 경우 읽는 법이나 메모를 추가한다.
6. 저장한다.

### 기대 결과

표현이 자신의 학습 목록에 저장되고 이후 검색과 퀴즈에서 사용할 수 있다.

### UX 요구사항

표현을 저장하는 과정이 복잡하면 사용자가 다시 메모장이나 스크린샷을 사용할 가능성이 높다.

따라서 MVP에서는 필수 입력값을 최소화한다.

필수:

* 일본어
* 한국어 뜻
* 단어 / 문장 구분

선택:

* 읽는 법
* 메모
* 출처
* 태그

# Scenario 2. 저장한 표현을 역번역으로 복습

### 상황

사용자는 이전에 여러 일본어 표현을 저장했다.

하지만 단순히 목록을 다시 읽는 것보다 자신이 실제로 해당 표현을 기억하고 있는지 확인하고 싶다.

### 사용자 목표

한국어만 보고 이전에 학습한 일본어 표현을 직접 떠올리고 싶다.

### 사용자 행동

1. Kotoba Loop에 로그인한다.
2. 퀴즈를 시작한다.
3. 화면에 한국어 뜻 또는 문장이 표시된다.
4. 사용자는 일본어 정답을 직접 입력한다.
5. 입력 후 저장된 모범 답안을 확인한다.
6. 자신의 답이 맞았는지 확인한다.
7. 다음 문제로 이동한다.

예:

```text
문제

멈춰 서다

일본어로 입력하세요.

[               ]
```

사용자 입력:

```text
立ち止まる
```

모범 답안:

```text
立ち止まる
```

### 기대 결과

사용자는 단순히 일본어를 다시 읽는 것이 아니라 정답을 보기 전에 직접 표현을 떠올리게 된다.

이를 통해 해당 표현이 실제로 기억에 남아 있는지 확인할 수 있다.

# Scenario 3. 틀린 표현 다시 학습

### 상황

사용자는 역번역 퀴즈를 진행하면서 일부 표현을 제대로 떠올리지 못했다.

기존 학습에서는 문제를 틀린 뒤 정답을 확인하는 것으로 끝나는 경우가 많았다.

### 사용자 목표

자신이 잘 기억하지 못하는 표현만 다시 모아서 학습하고 싶다.

### 사용자 행동

1. 퀴즈를 완료한다.
2. 퀴즈 결과에서 틀린 표현을 확인한다.
3. 틀린 표현이 오답 목록에 저장된다.
4. 사용자는 이후 `오답 복습`을 선택한다.
5. 이전에 틀렸던 표현만 다시 출제된다.
6. 사용자는 해당 표현을 다시 직접 입력한다.

### 기대 결과

사용자가 이미 알고 있는 표현을 계속 반복하는 대신 잘 기억하지 못하는 표현에 다시 노출된다.

이를 통해 한 번 틀린 표현이 학습 과정에서 사라지지 않고 다음 복습으로 이어진다.

# 핵심 사용자 흐름

세 가지 시나리오는 다음 하나의 학습 흐름으로 연결된다.

```text
새로운 표현 발견
        ↓
표현 저장
        ↓
학습 목록에 축적
        ↓
역번역 퀴즈
        ↓
일본어 직접 회상
        ↓
    ┌─────────┐
  정답        오답
    │           │
    │       오답 기록
    │           ↓
    │       오답 복습
    │           │
    └─────→ 반복 학습
```

Kotoba Loop의 MVP에서는 이 흐름이 끊기지 않고 동작하는 것을 가장 중요한 사용자 경험으로 정의한다.
